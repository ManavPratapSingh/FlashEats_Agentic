# Class 10 Agentic Coding Challenge

Your goal is to extend the existing FlashEats Operations application with the **At-Risk Orders Queue** described in `docs/features/at-risk-orders-starter.md`.

Do not start by asking the agent to implement the whole feature.

Recommended workflow:

1. Ask the agent to inspect the repository without modifying files.
2. Ask it to identify architecture, relevant business rules, tests, APIs, and ambiguities.
3. Produce or refine a feature spec with acceptance criteria and out-of-scope items.
4. Ask for a minimal implementation plan without code changes.
5. Review the plan for assumptions.
6. Implement one small task at a time.
7. Review every diff.
8. Run relevant tests after each meaningful change.
9. Verify the final behavior against the spec.

## Submission evidence

Capture:

- your repository-inspection prompt,
- your final feature spec,
- the agent's implementation plan,
- one generated diff you reviewed,
- tests you ran,
- at least one incorrect assumption or risky suggestion you caught,
- one decision where you overruled or redirected the agent.
